# Student Task Management Application

## Project Description
Student Task Manager is a simple web application that lets users add, display, complete, delete and search tasks. It was built by a two-person team to demonstrate a collaborative Git and GitHub workflow.

## Team Members
- Student 1: Shahroz BSDSF25A019 - GitHub: shahrozrashid31-star
- Student 2: Muhammad Ali BSDSF25A022  - GitHub: alifawad-dev

## Features
- Add a task with title, description and due date
- Display tasks as cards
- Mark tasks as completed or undo
- Delete tasks
- Search tasks by title
- Responsive layout for mobile screens

## Technologies
HTML, CSS, JavaScript, Git, GitHub

## Git Workflow
Feature branches were created from main, pushed to GitHub, reviewed by the other team member through Pull Requests and merged into main. Work was linked to GitHub Issues, a merge conflict was created and resolved, and version 1.0.0 was tagged and released.

## Branches
- main: stable code
- feature/task-form: task form and task logic (Student 1)
- feature/task-style: styling and responsive layout (Student 2)
- conflict/student1 and conflict/student2: README merge conflict demonstration
- feature/task-search: task search (Student 2)
- docs/readme: README documentation (Student 1)

## Git Commands Demonstrated
git init, git status, git add, git commit, git log, git branch, git switch, git diff, git diff --staged, git clone, git remote, git push, git fetch, git pull, git merge, git stash, git restore, git reset, git revert, git show, git blame, git tag

## GitHub Features Demonstrated
Repository, collaborators, branches, Issues, Pull Requests, code reviews, merging, closing an issue with Closes #1, tags, releases and contributors

## How to Run
1. Clone the repository: git clone https://github.com/shahrozrashid31-star/Task-manager.git
2. Open the Task-manager folder.
3. Open index.html in a web browser.
